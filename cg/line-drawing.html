🎯 Objective

To implement and understand the Digital Differential Analyzer (DDA) and Bresenham line-drawing algorithms. Enter two endpoints to see how each algorithm draws a line on the pixel grid.

1. Digital Differential Analyzer (DDA)

Algorithm

  1. Read the starting point (x1, y1) and ending point (x2, y2).
  2. Calculate dx = x2 − x1 and dy = y2 − y1.
  3. Calculate steps = max(|dx|, |dy|).
  4. Calculate xIncrement = dx / steps and yIncrement = dy / steps.
  5. Increment x and y at each step and plot the nearest pixel.

2. Bresenham Line Drawing Algorithm

Algorithm

  1. Read the two endpoints of the line.
  2. Calculate dx = |x2 − x1| and dy = |y2 − y1|.
  3. Determine the direction of movement along each axis.
  4. Use an integer decision parameter to select the next pixel.
  5. Continue until the endpoint is reached.

💻 Java Source Code

The following Java program implements both algorithms using Java Swing. Save the source code separately as LineDrawing.java. 

import javax.swing.*;
import java.awt.*;

public class LineDrawing extends JPanel {

    public void paintComponent(Graphics g) {
        super.paintComponent(g);

        // DDA Line
        g.setColor(Color.BLUE);
        drawDDA(g, 50, 70, 250, 200);

        // Bresenham Line
        g.setColor(Color.RED);
        drawBresenham(g, 300, 70, 500, 200);

        g.setColor(Color.BLACK);
        g.drawString("DDA Line", 100, 40);
        g.drawString("Bresenham Line", 350, 40);
    }

    void drawDDA(Graphics g, int x1, int y1, int x2, int y2) {
        int dx = x2 - x1;
        int dy = y2 - y1;

        int steps = Math.max(Math.abs(dx), Math.abs(dy));

        if (steps == 0) {
            g.fillRect(x1, y1, 2, 2);
            return;
        }

        float xInc = (float) dx / steps;
        float yInc = (float) dy / steps;

        float x = x1;
        float y = y1;

        for (int i = 0; i <= steps; i++) {
            g.fillRect(Math.round(x), Math.round(y), 2, 2);
            x += xInc;
            y += yInc;
        }
    }

    void drawBresenham(Graphics g, int x1, int y1,
                       int x2, int y2) {

        int dx = Math.abs(x2 - x1);
        int dy = Math.abs(y2 - y1);

        int sx = x1 < x2 ? 1 : -1;
        int sy = y1 < y2 ? 1 : -1;

        int error = dx - dy;

        while (true) {
            g.fillRect(x1, y1, 3, 3);

            if (x1 == x2 && y1 == y2) {
                break;
            }

            int e2 = 2 * error;

            if (e2 > -dy) {
                error -= dy;
                x1 += sx;
            }

            if (e2 < dx) {
                error += dx;
                y1 += sy;
            }
        }
    }

    public static void main(String[] args) {
        JFrame frame = new JFrame("Line Drawing Algorithms");

        frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        frame.setSize(600, 350);
        frame.setLocationRelativeTo(null);
        frame.add(new LineDrawing());
        frame.setVisible(true);
    }
}
