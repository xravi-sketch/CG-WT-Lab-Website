Program 4: Internal and External Linking in XHTML

Internal links navigate to sections on the same page. External links can open websites in a new tab.

Source Code

<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE html
    PUBLIC "-//W3C//DTD XHTML 1.0 Strict//EN"
    "http://www.w3.org/TR/xhtml1/DTD/xhtml1-strict.dtd">
<html xmlns="http://www.w3.org/1999/xhtml">
<head>
    <title>XHTML Linking Example</title>
</head>
<body>
    <h1 id="top">XHTML Linking Demonstration</h1>

    <h2>Internal Links</h2>
    <p><a href="#about">Go to About Section</a></p>
    <p><a href="#contact">Go to Contact Section</a></p>

    <h2>External Links</h2>
    <p><a href="https://www.google.com" target="_blank">Open Google</a></p>
    <p><a href="https://www.wikipedia.org" target="_blank">Open Wikipedia</a></p>

    <h2 id="about">About Section</h2>
    <p>This is the About section.</p>
    <p><a href="#top">Back to Top</a></p>

    <h2 id="contact">Contact Section</h2>
    <p>This is the Contact section.</p>
    <p><a href="#top">Back to Top</a></p>
</body>
</html>

Program 5: Registration Form Using XHTML

Demonstrates text fields, password, radio buttons, checkboxes, select, textarea, submit, and reset.

Source Code

<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE html
    PUBLIC "-//W3C//DTD XHTML 1.0 Strict//EN"
    "http://www.w3.org/TR/xhtml1/DTD/xhtml1-strict.dtd">
<html xmlns="http://www.w3.org/1999/xhtml">
<head>
    <title>Student Registration Form</title>
</head>
<body>
    <h1>Student Registration Form</h1>

    <form action="#" method="post">
        <p>
            <label for="xname">Full Name:</label>
            <input type="text" id="xname" name="name" />
        </p>

        <p>
            <label for="xemail">Email:</label>
            <input type="text" id="xemail" name="email" />
        </p>

        <p>
            <label for="xpassword">Password:</label>
            <input type="password" id="xpassword" name="password" />
        </p>

        <p>Gender:</p>
        <p>
            <input type="radio" id="xmale" name="gender" value="Male" />
            <label for="xmale">Male</label>
            <input type="radio" id="xfemale" name="gender" value="Female" />
            <label for="xfemale">Female</label>
        </p>

        <p>Interests:</p>
        <p>
            <input type="checkbox" id="xcoding" name="interest" value="Coding" />
            <label for="xcoding">Coding</label>
            <input type="checkbox" id="xsports" name="interest" value="Sports" />
            <label for="xsports">Sports</label>
        </p>

        <p>
            <label for="xcourse">Course:</label>
            <select id="xcourse" name="course">
                <option value="MCA">MCA</option>
                <option value="MBA">MBA</option>
                <option value="MSc">M.Sc</option>
            </select>
        </p>

        <p>
            <label for="xaddress">Address:</label>
            <textarea id="xaddress" name="address" rows="4" cols="30"></textarea>
        </p>

        <p>
            <input type="submit" value="Register" />
            <input type="reset" value="Clear" />
        </p>
    </form>
</body>
</html>
